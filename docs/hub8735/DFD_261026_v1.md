# HUB8735 資料流程圖（概念版）

> 2026-10-26更新：曲目分析改為背景執行，開機自動檢查新音樂，可與播放同時進行；仍可從選單手動要求分析。本文為概念圖，非目前程式的完整資料流，現況見[架構核對](../ARCHITECTURE.md)。綁帶由其他人實作，第4節僅為歷史方案。

細節見`HRMAX_MUSIC_FLOW.md`、`globalData.h`、`firmware/n76e003/ble-notify-data-format.md`。

## 1. 播放音樂

```mermaid
flowchart LR
    S["感測器<br/>手錶／綁帶（BLE）、本地IMU"]
    U["使用者<br/>OLED／序列埠"]
    LIB[("音樂資料<br/>檔名／BPM／曲風")]
    SPK["喇叭"]

    A("心率分析<br/>心率（或0x05原始PPG自算）→ HRmax → Zone → 目標BPM")
    C("控制<br/>選曲、模式、手動優先")
    P("播放<br/>播放MP3")

    S -- "心率／PPG／ACC" --> A
    A -- "目標BPM" --> C
    U -- "操作指令" --> C
    LIB -- "BPM" --> C
    C -- "播放命令" --> P
    P -- "播畢／失敗" --> C
    P -- "音訊" --> SPK
```

感測器心率 → 目標BPM → 控制選曲 → 播放；使用者指令可隨時插手（手動優先）。背景分析進行中選曲照常，只選已有有效BPM的歌。

## 2. BPM／曲風分析（背景）

```mermaid
flowchart LR
    BOOT["開機"]
    U["使用者<br/>OLED／序列埠"]
    LIB[("音樂資料<br/>檔名／BPM／曲風")]
    MP3[("SD卡MP3")]

    C("控制<br/>轉送請求")
    M("曲目分析（背景）<br/>BPM（bpm_tempo）<br/>曲風（NPU）")
    P("播放")

    BOOT -- "自動檢查新音樂" --> M
    U -- "分析請求<br/>(新檔／未知、全部重分析、清除全部)" --> C
    U -- "單曲BPM x2／÷2" --> C
    C -- "分析請求" --> M
    C -- "BPM修正" --> LIB
    MP3 -- "檔案清單、音檔" --> M
    LIB -- "既有紀錄（判斷新增／替換／未知）" --> M
    M -- "BPM、曲風" --> LIB
    M -- "進度／完成／失敗" --> C
    P -. "播放優先，分析只用空檔" .- M
```

- 開機時比對SD與曲庫，新增／替換檔與未知BPM或曲風的歌自動排入背景分析；開機後才放入的檔案要手動分析或重開機。
- 分析可與播放同時進行，播放優先，不得斷音；分析完成的歌立即可參與自動選歌。
- 使用者仍可隨時從選單手動要求「新檔／未知」或「全部重分析」；「清除全部」會先取消進行中的分析。
- 單曲失敗不影響其他曲目。

## 3. 感測器端（手錶）

```mermaid
flowchart LR
    PPG["PPG模組<br/>BMH08002-4"]
    IMU["IMU<br/>LSM6DS3"]
    HUB["HUB8735"]
    U["使用者<br/>按鍵"]
    OLED["OLED"]

    N("N76E003<br/>心率計算<br/>封包組成")
    B("BLE模組<br/>BM7701")

    PPG -- "UART PPG幀" --> N
    IMU -- "I2C ACC／GYRO" --> N
    N -- "UART指令＋資料" --> B
    B -- "BLE notify<br/>心率／IMU（1Hz）／0x05原始PPG" --> HUB
    U -- "切換頁面" --> N
    N -- "PPG／IMU數值、波形" --> OLED
```

手錶變體差在心率來源：模組心率（`ble_sensor`）、自算並送0x05（`ble_sensor_hr`）、抗運動自算（`ble_sensor_motion`、`ble_sensor_demo`）。手錶不參與曲目分析。

連線流程：重置BLE模組 → 設名稱 → 廣播 → 等連線與訂閱 → 持續送資料；斷線後重新廣播。
